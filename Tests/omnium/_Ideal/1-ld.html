§4. The trivial function at A implements the famous iteration of Lothar Collatz (1910-1990). The use of MULTIPLE at B triples and adds 1.

A int collatz(int x) {            /* A */
      Print out x4.1
      if (x % 2 == 0) return x/2;
B     return MULTIPLE*x + 1;      /* B */
  }
