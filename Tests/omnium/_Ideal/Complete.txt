S4 Mathematics.  Zolotarev's Lemma says that a!= 0 has a square root modulo a prime p
if and only if the rearrangement of { 0, 1, 2, ..., p-1} produced by multiplying
by a is an even permutation. That is, if σ(x) = ax ~mod~ p, then
 ({\frac {a}{p}}) = \cases{1 & if σ even,\cr
-1 & if σ odd.\cr}
