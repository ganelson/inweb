§2. Markdown rendering instructions. While the code in this section renders the weave tree, the actual commentary (along with other fragments, such as comments in code, depending on the conventions used) is stored in Markdown, and needs to be handed over to the code in Markdown Rendering (in foundation).

That needs a set of instructions, to say what kind of Markdown, how we want it rendered, and so on.

markdown_render PlainTextWeaving::Markdown_instructions(weave_order *wv) {
    markdown_render rdr = MDRender::contextual_plain_text(
        WebNotation::commentary_variation(wv->weave_web),
        STORE_POINTER_weave_order(wv));
    return rdr;
}

§3. Rendering. The weave tree will be rendered by traversing it, and rendering each node in its turn.

void PlainTextWeaving::render(weave_format *self, text_stream *OUT, heterogeneous_tree *tree) {
    weave_document_node *C = RETRIEVE_POINTER_weave_document_node(tree->root->content);
    PlainText_render_state prs;
    Initialise the render state3.2;
    Trees::traverse_from(tree->root, &PlainTextWeaving::render_visit, (void *) &prs, 0);
}

§4. So, then, the visiting function, called on each node. C does not allow switch statements whose cases are not literal constants, so there's a big contrived if instead. But it is morally a switch.

int PlainTextWeaving::render_visit(tree_node *N, void *state, int L) {
    PlainText_render_state *prs = (PlainText_render_state *) state;
    text_stream *OUT = prs->OUT;

    /* Document superstructure */

         if (N->type == weave_document_node_type) Skip4.1
    else if (N->type == weave_head_node_type) Skip4.1
    else if (N->type == weave_body_node_type) Skip4.1
    else if (N->type == weave_tail_node_type) Skip4.1

    /* Large-scale structure */

    else if (N->type == weave_chapter_node_type) Skip4.1
    else if (N->type == weave_chapter_header_node_type) Render chapter header4.3
    else if (N->type == weave_chapter_footer_node_type) Skip4.1
    else if (N->type == weave_section_node_type) Skip4.1
    else if (N->type == weave_section_header_node_type) Render section header4.4
    else if (N->type == weave_section_footer_node_type) Render section footer4.5
    else if (N->type == weave_section_purpose_node_type) Render section purpose4.6
    else if (N->type == weave_toc_node_type) Skip4.1
    else if (N->type == weave_toc_line_node_type) Skip4.1

    /* Small-scale structure */

    else if (N->type == weave_subheading_node_type) Render subheading4.7
    else if (N->type == weave_subsubheading_node_type) Render subsubheading4.8
    else if (N->type == weave_paragraph_heading_node_type) Render paragraph heading4.9
    else if (N->type == weave_material_node_type) Skip4.1

    /* Code-like material */

    else if (N->type == weave_holon_declaration_node_type) Render holon declaration4.10
    else if (N->type == weave_code_line_node_type) Render code line4.11
    else if (N->type == weave_holon_usage_node_type) Render holon usage4.12
    else if (N->type == weave_tangler_command_node_type) Skip4.1
    else if (N->type == weave_verbatim_node_type) Render verbatim4.13
    else if (N->type == weave_source_code_node_type) Render source code4.14
    else if (N->type == weave_function_defn_node_type) Render function defn4.15
    else if (N->type == weave_function_usage_node_type) Render function usage4.16
    else if (N->type == weave_comment_in_holon_node_type) Render comment in holon4.17
    else if (N->type == weave_defn_node_type) Render defn4.18

    /* Commentary and gadget material */

    else if (N->type == weave_markdown_node_type) Render Markdown4.19
    else if (N->type == weave_audio_node_type) Skip4.1
    else if (N->type == weave_carousel_slide_node_type) Skip4.1
    else if (N->type == weave_download_node_type) Skip4.1
    else if (N->type == weave_embed_node_type) Render embed4.20
    else if (N->type == weave_figure_node_type) Skip4.1
    else if (N->type == weave_raw_HTML_node_type) Skip4.1
    else if (N->type == weave_video_node_type) Skip4.1

    /* Paragraph tail material */

    else if (N->type == weave_index_begins_node_type) Render index begins4.21
    else if (N->type == weave_index_lemma_node_type) Render index lemma4.22
    else if (N->type == weave_index_ends_node_type) Render index ends4.23
    else if (N->type == weave_endnote_node_type) Render endnote4.2
    else if (N->type == weave_locale_node_type) Render locale4.24
    else if (N->type == weave_endnote_text_node_type) Render endnote text4.25

    else internal_error("no HTML rendering for this node type");
    return TRUE;
}

§4.2.1. By default, the visitor function returns TRUE at each node (see above). This tells the tree-traversing machinery to continue recursing down through that node's children after the node itself has been visited.

Some nodes, however, will want to render something, then recurse downwards, then render something further. They can do this by using the following holon to perform the recursion, but must then explicitly return FALSE, or else the child nodes will end up being visited a second time.

Recurse the renderer through children nodes4.2.1 =

    for (tree_node *M = N->child; M; M = M->next)
        Trees::traverse_from(M, &PlainTextWeaving::render_visit, (void *) prs, L+1);
